The same amount,

Imaging mass spectrometry tells you where a metabolite is, then most analyses throw that away and ask only how much. MORTIS tests both — at the patient level, where the statistics are actually valid.

The flaw this package exists to fix

A tissue section has 30,000 pixels and one patient.

Test those pixels as independent replicates and you inflate your sample size by four orders of magnitude. The p-values that come out are not small because the biology is strong. They are small because n is wrong.

Here is what that costs, measured. Six simulated patients, three per arm, 500 pixels each, 200 metabolites — and no group difference at all, only the ordinary variation between patients:

Pixel-level test · n = 1,500 per arm 0/200

metabolites called significant at FDR < 0.05, on data containing nothing to find. Roughly 92% of the findings were manufactured by the method.

Patient-level test · n = 3 per arm 0/200

significant. The correct answer, from the same data, by counting patients instead of pixels.

This is not a subtle statistical preference. It is the difference between a result and an artefact, and it is documented for imaging mass spectrometry specifically — a published pixel-level t-test reporting P = 9.6 × 10⁻⁷ where the correct patient-level test gives P = 0.78.

So pseudobulk() comes first, and the pixel-level function still available for genuine within-section comparisons raises a warning that names the risk.

What imaging can see that bulk cannot

Two sections. Identical total signal.

Abundance testing asks whether there is more of something — the question bulk metabolomics already answers. Run it on imaging data and you have paid for spatial resolution to discard it.

A metabolite can sit at exactly the same abundance in two patients and be arranged completely differently: diffuse and even in one, pooled into sharp foci in the other. Lactate spread through a section and lactate concentrated in hypoxic cores are not the same biology, and no abundance test can tell them apart.

Step one

Measure how much.

pseudobulk() collapses every pixel in a section to one profile per patient. Twelve sections, twelve numbers per metabolite — the unit the statistics are actually valid at.

Spermidine comes back identical in both arms. Cliff's δ = 0.00. A bulk experiment would stop here and report nothing.

Step two

Then measure how it sits.

spatial_organization() collapses the same sections to arrangement instead — Moran's I, normalised entropy, Gi* hotspot fraction, Gini. One number per section per metabolite, scale-free so a big biopsy cannot outscore a small one.

Every responder concentrates spermidine into a focus. Every non-responder spreads it. δ = 1.00, FDR = 0.002.

Step three

Ask which axis moved.

compare_abundance_and_organization() places every metabolite on both and labels it. Four polyamines land at abundance δ = 0, organization δ = 1.0.

Same amount. Different arrangement. Only imaging can see this, and only if you look for it.

And the honest part

This needs six sections per group. Measured, not assumed: on a benchmark with three planted organization-only differences among thirty metabolites, effect size alone over-called at every cohort size, while effect size plus FDR gave exactly three true and zero false positives from n = 6 upward — and nothing at all below it. A Mann-Whitney comparison of five against five bottoms out at p = 0.0079, which cannot survive multiple-testing correction. Below six, an empty result is the correct answer.

End to end

Instrument export to submitted figure.

Eleven stages on one AnnData object. Every stochastic step takes a seed; every seeded step gives the same answer on a different machine.

Quickstart

The whole cohort analysis

import mortis as mt

# Load, clean, normalise
adatas       = mt.load_from_folder("./sections")
clean, stats = mt.filter_background(adatas, cutoff=1.5)
adata        = mt.preprocess(mt.merge_samples(clean))

# Collapse pixels to patients — never test pixels across patients
pb  = mt.pseudobulk(adata, sample_key="patient")
org = mt.spatial_organization(adata, sample_key="section")

# Test both axes at the patient level
ab   = mt.differential_abundance(pb,  "response", "R", "NR")
do   = mt.differential_spatial_organization(org, "response", "R", "NR")
both = mt.compare_abundance_and_organization(ab, do)

# Identifiers and pathways, in one call
ids, paths = mt.annotate_pathways(adata, ab)

# Figures — vector PDF, text stays editable
mt.set_publication_style(latex=True)
fig = mt.plot_abundance_vs_organization(both)
mt.save_figure(fig, "figures/fig3", provenance={"cohort": "vedo", "seed": 0})

For the reviewer

Prove it reproduces, without sending the data.

"Available on reasonable request" verifies nothing. A reviewer who doubts a result can take it on trust, ask for data the ethics approval forbids sharing, or reimplement your methods paragraph. None of those is checking.

export_manifest() writes a sealed JSON recording the environment, every step and its seeds, and a checksum of the inputs and of every result table. verify_manifest() re-runs the comparison and names precisely what diverged.

Checksums are one-way. Nothing in the file can be turned back into an intensity, so it is safe to attach to a submission for a cohort that can never leave the institution — which is the situation clinical imaging data is always in. 

# after the analysis
mt.export_manifest("manifest.json", adata=pb,
                   results={"abundance": ab, "organization": do},
                   analysis="vedolizumab week 14")

# anyone re-running it, months later
report = mt.verify_manifest("manifest.json", adata=pb, results=...)

Output

Figures you can hand to a co-author.

PDF text stays text — embedded TrueType with a character map, so a collaborator can retype a label in Illustrator and a reviewer can search the file. Only dense scatter interiors are rasterised; axes and labels never are.

Every figure carries its analysis parameters and a hash in the PDF metadata, so pdfinfo figure.pdf identifies the run that made it months later.

Why you can trust the output

Correctness is a claim you have to be able to check.

Every number here is measured on this machine and pinned by a test that fails on the code as it stood before the fix.

Spatial statistics stream over metabolite tiles, so a cohort that used to need 4.3 GB of working memory now needs 0.99 GB and runs twice as fast — with bit-identical checksums. Sparse and disk-backed matrices give the same answers as dense ones, and tile size is a memory dial that never changes a result.
